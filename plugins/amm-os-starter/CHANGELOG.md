# Changelog

## 2.2.0

Tasks and an AI crew (Complete level):

- **`Tasks/` folder** with one file per task (`T-0001-short-title.md`): what is wanted, "Done when", an append-only log and a draft result. Statuses: backlog, ready, in progress, review, done, blocked.
- **Three modes:** "add a task", "show the board" and "work the next task". The work is draft only: nothing is sent or published, and only the owner moves a task to done.
- **Board** (`board.html`): a single page with columns, filters, a "waiting for you" lane, overdue marks, task details with the log and draft, and a **Crew** panel built from the log. Optional auto-refresh.
- **Three agents** shipped with the plugin: Writer, Researcher and Checker. They are read-only (they return text; the main assistant writes files). The log records whether a step was done by a real sub-agent or inline, and the board shows it.
- New check in Check mode for stuck, overdue or malformed tasks.

Upgrade from 2.1.0: say "upgrade my second brain". An empty `Tasks/` folder, one table row, one rule and a `.claudeignore` line are added. Nothing you wrote is changed.

Known limit: whether sub-agents run inside the Claude desktop app or Cowork has not been verified. When they do not, the main assistant plays each role inline and logs it that way.

## 2.1.0

Three small changes, prompted by a review of retrieval and memory practices:

- **Index lines say what question each note answers** (`answers "..."`), so the right note is easier to find as the Second Brain grows.
- **Dated prices.** `offers-and-prices.md` has a "Prices valid as of" line. Check mode asks you to confirm prices older than 90 days, and the assistant says so before quoting an old price.
- **End-of-session capture** (Complete level). After meaningful work, the assistant offers a short journal entry: what was decided and why, what worked or failed, and what comes next. The Journal gains a "What worked or failed" section.

Upgrade from 2.0.0: say "upgrade my second brain". Your own notes are not rewritten. You will be asked to confirm that your prices are still current.

## 2.0.0

The whole skill is now in English: instructions, interview, generated files, folder and file names, README.

Changes:

- Published through the AMM marketplace (`AiMagicMakers/amm-marketplace`): install with `/plugin marketplace add` then `/plugin install amm-os-starter@amm-marketplace`.
- Packaged as a Claude plugin: `.claude-plugin/plugin.json` at the ZIP root and the skill in `skills/amm-os-starter/`. A ZIP with the skill inside a wrapper folder is rejected by the upload check.
- New references: `map-mode.md` and `update-and-complete.md` (the Update and Move to Complete procedures were missing).
- Folder names are English: `Context/`, `Projects/`, `Resources/`, `Archive/`. Context files are `identity.md`, `offers-and-prices.md`, `clients.md`, `style.md`, `processes.md`, `tools.md`, `goals.md`, `rules.md`.
- The marker for missing information is `[TO COMPLETE]`.
- The map file is `graph.html`, generated by `scripts/graph.py` from `references/graph-template.html`.
- Modes are named in English: Update, Move to Complete, Check, Add a document, Show the map, Upgrade.
- Fixes from the first end-to-end test: one `[TO COMPLETE]` line per section instead of one per bullet, `Open question` lines when a document conflict is left undecided, no figures in index descriptions, project status and deadline taken as the person says them.
- Folders built by 1.x versions are not upgraded automatically (the structure was renamed). They can be rebuilt by running the interview again.

Features carried over from 1.x:

- Three-round interview, Essential and Complete levels, `CLAUDE.md` routing at the root and in each folder, `AGENTS.md`, one-page `brief.md`, `.claudeignore`.
- `index.md` catalogue, `Resources/sources/` for original documents, `sources` field in every `Context/` file, answers that name the file used.
- Check mode (read-only health report), Add mode (bring in a new document, showing conflicts), Map mode (interactive `graph.html`), and the reusable-text rule.
- `skill_version` in the root `CLAUDE.md` and an Upgrade mode that only adds.
